wgpu-py on Dawn (Cython backend), in Pyodide, on your GPU

This page loads Pyodide and installs a wgpu wheel that contains the Dawn backend as a compiled Cython extension (built with pyodide build against Dawn's Emdawnwebgpu). It then runs demo.py: a compute shader and a rendered triangle, through the browser's WebGPU (hardware accelerated). The same backend code also runs natively on Dawn. See pygfx/wgpu-py#839 and #838. The variant with cffi bindings (#840) is at cffi/.
